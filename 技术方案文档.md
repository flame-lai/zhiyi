## 1. 技术选型总览

| 维度 | 选型 | 说明 |

| Web前端 | Vue 3 + Vite + Ant Design Vue 4.x + Pinia | PC端管理后台 |

### 2.2 多租户方案

采用**共享数据库 + `factory_id` 字段**方案，通过 MyBatis-Plus 多租户插件自动为业务 SQL 追加 `WHERE factory_id = ?` 条件，实现数据隔离。

- 适用于多工厂/集团化场景
- 所有业务表包含 `factory_id` 字段
- `factory` 表本身不做租户过滤
- 请求拦截器从 JWT 中解析 `factory_id`，放入 ThreadLocal

### 2.3 租户识别方式

所有工厂访问同一个地址，通过**登录账号自动识别所属工厂**，用户无需手动选择工厂。

**登录流程**：
```
用户访问 https://erp.zhiyi.com（所有工厂相同）
        ↓
    输入账号密码/工号
        ↓
后端根据账号查到所属的 factory_id
        ↓
Token 中携带 factory_id + factory_name
        ↓
后续所有请求自动带上 factory_id，数据自动隔离
```

**业务规则**：
- 登录账号全局唯一，一个账号只属于一个工厂
- 不同工厂可以有相同的工号，但登录账号不能重复
- 登录后页面展示工厂名称，让用户明确知道自己在哪个工厂的操作环境

## 4. 数据库设计

### 4.1 设计原则

- 所有业务表包含 `factory_id` 字段（多租户隔离）
- 金额字段使用 `DECIMAL(12,2)`
- 时间字段使用 `DATETIME`，默认 `CURRENT_TIMESTAMP`
- 主键使用 `BIGINT` 自增
- 逻辑删除字段 `deleted`（0未删除，1已删除）
- 创建/更新时间 `created_at`、`updated_at`
- 创建/更新人 `created_by`、`updated_by`

### 5.4 多租户实现

采用 MyBatis-Plus 内置多租户插件，对业务 SQL 自动追加 `WHERE factory_id = ?` 条件。

```java
// TenantContext.java - 租户上下文（ThreadLocal）
public class TenantContext {
    private static final ThreadLocal<Long> TENANT_ID = new ThreadLocal<>();
    public static void set(Long factoryId) { TENANT_ID.set(factoryId); }
    public static Long get() { return TENANT_ID.get(); }
    public static void clear() { TENANT_ID.remove(); }
}

// TenantInterceptor.java - 请求拦截器
@Component
public class TenantInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest request, ...) {
        // 从JWT解析factory_id，放入TenantContext
        Long factoryId = JwtUtil.getFactoryId(request);
        TenantContext.set(factoryId);
        return true;
    }

    @Override
    public void afterCompletion(...) {
        TenantContext.clear(); // 防止内存泄漏
    }
}

// MybatisPlusConfig.java - MP配置
@Configuration
public class MybatisPlusConfig {
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        // 多租户插件
        interceptor.addInnerInterceptor(new TenantLineInnerInterceptor(new TenantLineHandler() {
            @Override
            public Expression getTenantId() {
                return new LongValue(TenantContext.get());
            }
            @Override
            public String getTenantIdColumn() {
                return "factory_id";
            }
            @Override
            public boolean ignoreTable(String tableName) {
                return "factory".equals(tableName); // factory表不做租户过滤
            }
        }));
        // 分页插件
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return interceptor;
    }
}
```

### 6.3 Axios 请求封装

```typescript
// api/request.ts
const service = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL, // /api
  timeout: 15000,
});

// 请求拦截器：自动携带Token
service.interceptors.request.use((config) => {
  const token = getToken();
  if (token) {
    config.headers['Authorization'] = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截器：统一处理错误
service.interceptors.response.use(
  (response) => {
    const res = response.data;
    if (res.code !== 200) {
      if (res.code === 401) {
        useUserStore().logout();
        router.push('/login');
      }
      message.error(res.message || '请求失败');
      return Promise.reject(new Error(res.message));
    }
    return res.data;
  },
  (error) => {
    message.error(error.message || '网络异常');
    return Promise.reject(error);
  }
);
```

const handleScan = async () => {
  try {
    // 1. 调用小程序扫码API
    const res = await Taro.scanCode({ scanType: ['qrCode', 'barCode'] });
    const codeStr = res.result;

    if (codeStr.startsWith('CUT')) {
      // 裁床条形码 (整床) → 整床报工

    }
  } catch (err) {
    Taro.showToast({ title: '扫码失败', icon: 'error' });
  }
};

## 8. 打印方案

### 8.1 方案说明

采用**前端生成标签 + 浏览器原生打印**方案，无需额外部署打印服务。

**优点**：
- 零额外部署，支持任意打印机（USB、网络、热敏）
- 浏览器会记住上次选的打印机，第二次以后直接打印
- 批量打印支持（一页排多张标签）

### 8.2 打印流程

**单张打印**：
```
点击"打印菲仔" → 前端渲染标签（HTML/Canvas）→ 打开新窗口调用 window.print() → 选择打印机 → 打印完成
```

**批量打印**：
```
点击"批量打印" → 前端生成PDF（一页排4-6张标签）→ 浏览器打印PDF → 一次打完
```

## 10. 安全设计
