# 模块2：订单与配料 - 需求文档

## 概述

订单与配料模块是业务核心，负责管理客户订单、工序定价、物料清单和出货。采用「订单头 + 订单明细」的二级结构，支持一个订单包含多个款号。

---

## 数据结构总览

```
订单头（订单号、客户、订单金额、状态）
  └── 订单明细1：款号A + 颜色1 + 尺码1 + 数量
       ├── 工序定价（该款号的工序列表+工价）
       ├── 物料清单（该款号的物料列表）
       └── 出货记录
  └── 订单明细2：款号A + 颜色2 + 尺码2 + 数量
       ├── 工序定价
       ├── 物料清单
       └── 出货记录
  └── 订单明细3：款号B + 颜色1 + 尺码1 + 数量
       ├── 工序定价
       ├── 物料清单
       └── 出货记录
```

---

## 2.1 订单创建与管理

### 页面布局
- **列表页**：订单列表 + 搜索栏 + 新增按钮
- **详情页**：订单头信息 + 订单明细列表 + 每条明细的工序/物料/出货

### 订单列表页字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 订单号 | 文本 | 系统自动生成，如 ORD20240101001 |
| 客户 | 文本 | 从客户档案选择 |
| 款号明细 | 文本 | 展示该订单包含的所有款号，逗号分隔 |
| 总件数 | 数字 | 自动汇总所有明细的数量合计 |
| 订单金额 | 数字 | 手动输入，整单总金额 |
| 计划交期 | 日期 | |
| 订单状态 | 标签 | 待确认/已确认/生产中/部分出货/已完工/已出货/已结算 |
| 操作 | 按钮 | 编辑、查看详情、删除 |

### 新增订单弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 订单号 | 文本 | 系统生成 | 自动生成，如 ORD20240101001 |
| 客户 | 下拉选择 | 是 | 从客户档案选择 |
| 订单金额 | 数字 | 否 | 整单总金额，可后续补充 |
| 计划交期 | 日期 | 否 | |

### 添加订单明细

在订单详情页中，点击「添加明细」按钮，弹出弹窗：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 款号 | 下拉选择/手动输入 | 是 | 可从款号库选择，也可手动输入新值。输入的新款号自动添加到款号库 |
| 颜色 | 文本 | 是 | 支持多个颜色 |
| 尺码 | 文本 | 是 | 支持多个尺码 |
| 数量 | 数字 | 是 | |

**颜色尺码矩阵**：
- 选择款号后，支持以「颜色×尺码」矩阵形式录入数量
- 行 = 颜色（可多行），列 = 尺码（可多列），格子 = 数量
- 总件数自动汇总矩阵中所有格子的数量

### 订单状态管理

#### 状态定义

| 状态 | 标签颜色 | 说明 |
|------|---------|------|
| 待确认 | 灰色 | 订单刚创建，默认状态 |
| 已确认 | 蓝色 | 管理员手动点击「确认订单」 |
| 生产中 | 橙色 | 裁床开菲后自动变更 |
| 部分出货 | 黄色 | 有出货记录但未出齐 |
| 已完工 | 紫色 | 所有扎号全部工序完成（系统自动检测） |
| 已出货 | 绿色 | 所有明细行出货数量 ≥ 数量 |
| 已结算 | 深灰 | 管理员手动点击「标记结算」 |

#### 状态流转规则

| 当前状态 | 可流转到 | 触发方式 |
|---------|---------|---------|
| 待确认 | 已确认 | 管理员手动确认 |
| 已确认 | 生产中 | 裁床开菲后自动变更 |
| 生产中 | 部分出货 | 有出货记录 |
| 生产中 | 已完工 | 系统自动检测所有扎号完成 |
| 部分出货 | 已完工 | 系统自动检测所有扎号完成 |
| 部分出货 | 已出货 | 所有明细行出齐 |
| 已完工 | 已出货 | 所有明细行出齐 |
| 已出货 | 已结算 | 管理员手动标记 |

#### 自动状态判断

| 条件 | 自动变更状态 |
|------|------------|
| 某明细行的出货数量 > 0 且 < 该行数量 | 订单状态 → 部分出货 |
| 所有明细行的出货数量 ≥ 该行数量 | 订单状态 → 已出货 |
| 所有扎号全部工序完成 | 订单状态 → 已完工 |

### 业务规则
- 订单号由系统自动生成，唯一不可修改
- 确认订单后才能进行裁床开菲操作
- 已删除的订单不可恢复，关联的扎号、报工记录等一并逻辑删除
- 订单金额为手动输入的整单金额，不自动计算

## 2.2 订单工序定价

### 功能说明
每个款号有独立的工序定价。创建订单明细后，自动带出该款号的标准工序路由，管理员可在订单维度独立修改。

### 页面位置
在订单详情页中，每条订单明细下方展示该款号的工序定价列表。

### 列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 排序 | 数字 | 拖拽调整顺序，不影响标准模板 |
| 工序名称 | 文本 | 带出，不可修改 |
| 订单工价 | 数字 | 默认带出标准模板参考价，可修改 |

### 操作功能

| 功能 | 说明 |
|------|------|
| 修改工价 | 直接编辑「订单工价」列，不影响标准模板 |
| 拖拽排序 | 调整该款号在本订单中的工序顺序 |
| 添加工序 | 从工序库中选择已有工序添加 |
| 快速新增工序 | 在工序搜索下拉中，若无匹配项，底部显示「+ 新增工序：xxx」，点击弹出轻量弹窗填写分类、名称、参考工价，确认后同时添加到工序库和当前订单 |
| 删除工序 | 移除该工序（仅移除本订单的，不影响工序库） |

### 业务规则
- 同一款号在同一订单下工序不可重复
- 修改工价仅影响当前订单，不影响款号标准模板
- 快速新增的工序同时写入工序库，后续订单可用

## 2.3 订单物料清单

### 功能说明
每个款号有独立的物料清单。自动带出该款号的标准物料清单，总用量根据该款号的数量自动计算。

### 页面位置
在订单详情页中，每条订单明细下方展示该款号的物料清单列表（与工序定价并列或Tab切换）。

### 列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 物料名称 | 文本 | 带出，可修改 |
| 类型 | 标签 | 原料/辅料 |
| 总用量 | 数字 | 自动计算：单件用量 × 该款号数量，可手动覆盖 |
| 单位 | 文本 | 带出 |
| 备注 | 文本 | 可填写，如「供应商已确认」「需采购」 |
| 已齐料 | 勾选框 | 打勾表示该物料已到齐 |
| 齐料信息 | 文本 | 勾选人 + 勾选时间（灰色小字） |

### 操作功能

| 功能 | 说明 |
|------|------|
| 添加物料 | 新增一行，填写物料名称、类型、总用量、单位 |
| 删除物料 | 移除该物料 |
| 编辑 | 直接在列表中修改总用量、备注 |
| 勾选已齐料 | 勾选后自动记录操作人和操作时间 |

### 业务规则
- 总用量默认 = 单件用量 × 该款号数量，可手动覆盖
- 「已齐料」勾选后记录当前操作人和时间，可取消勾选
- 物料名称手动输入，不关联库存系统
- 该清单仅作为信息同步和备料打勾使用，不进行库存扣减

## 2.4 出货管理

### 功能说明
在订单详情页中管理出货，按明细行（款号+颜色+尺码）维度记录出货。

### 页面位置
在订单详情页中，每条订单明细下方展示出货记录列表。

### 出货记录列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 出货日期 | 日期 | |
| 款号 | 文本 | 关联的款号 |
| 颜色 | 文本 | |
| 尺码 | 文本 | |
| 出货数量 | 数字 | 本次出货件数 |
| 备注 | 文本 | |

### 出货进度展示

在订单明细行上展示出货进度：

| 字段 | 说明 |
|------|------|
| 该行数量 | 如 200件 |
| 已出货数量 | 如 120件 |
| 出货进度 | 如 60%（进度条） |
| 状态 | 未出货/部分出货/已出齐 |

### 操作功能

| 功能 | 说明 |
|------|------|
| 新增出货 | 选择明细行，填写出货日期、数量、备注 |
| 查看出货记录 | 展示该明细行的所有出货历史 |
| 删除出货记录 | 删除某条出货记录，回退出货数量 |

### 业务规则
- 出货数量不能超过该明细行的剩余可出数量（可配置是否允许超发）
- 新增出货记录后，自动更新明细行的已出货数量
- 删除出货记录后，自动回退已出货数量
- 所有明细行都出齐后，订单状态自动变为「已出货」

---

## 模块总结

| 子模块 | 核心功能 |
|--------|---------|
| 订单创建 | 订单头+明细二级结构，支持多款号，颜色尺码矩阵录入 |
| 订单工序定价 | 每个款号独立工序定价，支持快速新增工序 |
| 订单物料清单 | 每个款号独立物料清单，备料打勾记录操作人和时间 |
| 出货管理 | 按款号+颜色+尺码维度记录出货，自动更新订单状态 |
| 订单状态 | 待确认→已确认→生产中→部分出货→已完工→已出货→已结算 |
