# 模块1：基础配置 - 需求文档

## 概述

基础配置模块是整个ERP系统的地基，用于管理全厂通用的基础数据。包括员工、工序、款号、客户、供应商等核心主数据。

---

## 1.1 员工档案管理

### 功能说明
管理全厂员工的基本信息，生成专属登录码供工人免密登录扫码报工。

### 页面布局
- **列表页**：员工列表 + 搜索栏 + 新增按钮
- **弹窗**：新增/编辑员工信息

### 列表页字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 工号 | 文本 | 系统自动生成，格式如 A001、A002... |
| 姓名 | 文本 | |
| 手机号 | 文本 | 用于联系 |
| 角色 | 标签 | 从权限管理中选择的角色名称 |
| 账号状态 | 标签 | 启用（绿色）/ 停用（灰色） |
| 登录码 | 文本+操作 | 展示登录码，支持「查看」和「重置」 |
| 登录账号 | 文本 | Web端登录账号，默认等于工号 |
| 操作 | 按钮 | 编辑、停用/启用、重置登录码、重置密码 |

### 新增/编辑弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 工号 | 文本 | 系统生成 | 自动递增，如 A001、A002 |
| 姓名 | 文本 | 是 | |
| 手机号 | 文本 | 否 | |
| 角色 | 下拉选择 | 是 | 从「权限管理-角色管理」中选择，决定可使用的功能和可访问的平台 |
| 登录账号 | 文本 | 否 | 用于Web端登录，默认等于工号，可修改 |
| 登录密码 | 文本 | 否 | 用于Web端登录，管理员设置初始密码 |
| 登录码 | 文本 | 系统生成 | 用于移动端登录 |
| 备注 | 文本 | 否 | |

### 操作功能

| 功能 | 说明 |
|------|------|
| 新增员工 | 打开弹窗填写信息，工号自动生成 |
| 编辑 | 修改员工信息 |
| 停用/启用 | 停用后该员工无法扫码报工，历史数据保留 |
| 生成登录码 | 新增员工时自动生成专属登录码（一串字符或二维码） |
| 重置登录码 | 重置后旧登录码失效，需重新打印给工人 |
| 搜索 | 按工号、姓名模糊搜索 |

### 业务规则
- 工号由系统自动生成，格式为字母+三位数字（A001、A002...）
- 每个员工有唯一登录码，用于移动端（微信小程序）登录
- 登录账号默认等于工号，可手动修改，用于Web管理后台登录
- 登录密码由管理员设置初始密码，员工可自行修改
- 停用员工不影响已有报工记录和工资数据
- 角色决定了员工可以访问哪些平台（Web端/移动端）和功能

## 1.2 工序库

### 功能说明
定义全厂标准工序，支持分类管理。工序是生产流转的基本单位，后续订单工序路由从此处选择。

### 页面布局
- **列表页**：按分类分组展示的工序表格 + 新增按钮
- **弹窗**：新增/编辑工序

### 列表页字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 排序号 | 数字 | 支持拖拽调整顺序 |
| 分类 | 文本 | 如：裁剪类、车缝类、后整类、质检类 |
| 工序名称 | 文本 | 如：裁剪、车领、钉扣、质检、包装 |
| 参考工价 | 数字 | 全局默认工价，订单可覆盖 |
| 操作 | 按钮 | 编辑、删除 |

### 新增/编辑弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 分类 | 下拉选择 | 是 | 可选择已有分类或输入新分类 |
| 工序名称 | 文本 | 是 | |
| 参考工价 | 数字 | 是 | 单位：元/件 |

### 操作功能

| 功能 | 说明 |
|------|------|
| 新增工序 | 打开弹窗填写信息 |
| 编辑 | 修改工序信息 |
| 删除 | 删除该工序 |
| 拖拽排序 | 拖拽调整工序顺序，顺序影响后续工序路由的默认排列 |
| 分类筛选 | 按分类筛选工序 |

### 业务规则
- 工序分类支持自定义，输入新分类时自动创建
- 已被订单使用的工序**禁止删除**，提示「该工序已被订单使用，无法删除」
- 排序号影响后续款号模板和订单工序的默认顺序

## 1.3 款号管理

### 功能说明
管理款号（SPU）基础信息，每个款号关联一套标准工序路由和标准物料清单。

### 页面布局
- **列表页**：款号列表 + 搜索栏 + 新增按钮
- **详情页**：款号信息 + 两个Tab（标准工序路由、标准物料清单）

### 列表页字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 款号 | 文本 | 手动编码，如 SP-2024001 |
| 款式名称 | 文本 | 如：圆领T恤、polo衫 |
| 操作 | 按钮 | 编辑、删除、查看详情 |

### 新增/编辑弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 款号 | 文本 | 是 | 手动输入，唯一标识 |
| 款式名称 | 文本 | 是 | |

### 业务规则
- 款号手动编码，系统校验唯一性
- 已关联订单的款号**禁止删除**，提示「该款号已被订单使用，无法删除」
- 点击「查看详情」进入款号详情页

---

## 1.4 款号标准模板配置

### 功能说明
挂在款号详情页下，配置该款号的标准工序路由和标准物料清单。订单创建时会自动带出这些标准配置，支持在订单维度独立微调。

### 页面布局
在款号详情页内，分两个Tab展示：

---

### Tab1：标准工序路由

#### 列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 排序 | 数字 | 拖拽调整顺序 |
| 工序名称 | 下拉选择 | 从工序库中选择 |
| 参考工价 | 数字 | 默认带出工序库的参考价，可修改 |

#### 操作功能

| 功能 | 说明 |
|------|------|
| 添加工序 | 从工序库中选择工序添加到路由 |
| 删除工序 | 从路由中移除 |
| 拖拽排序 | 调整工序顺序 |
| 修改工价 | 直接编辑参考工价 |

#### 业务规则
- 同一款号下工序不可重复添加
- 排序决定订单创建时工序的默认展示顺序

---

### Tab2：标准物料清单

#### 列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 物料名称 | 文本 | 如：白色棉布、拉链、吊牌 |
| 类型 | 单选 | 原料 / 辅料 |
| 单件用量 | 数字 | 如 1.5 |
| 单位 | 文本 | 自定义，如：米、个、条、码 |

#### 操作功能

| 功能 | 说明 |
|------|------|
| 添加物料 | 新增一行，填写物料信息 |
| 删除物料 | 移除该物料 |
| 编辑 | 直接在列表中修改 |

#### 业务规则
- 物料名称手动输入，不关联库存
- 单位支持自定义输入
- 此清单为标准模板，订单创建时自动带出，可在订单维度独立修改

## 1.7 物料管理

### 功能说明
管理物料主数据（原料：面料、里布等；辅料：拉链、纽扣、线、吊牌、包装袋等），订单配料时可从此处选择，也支持自定义输入。

### 页面布局
- **列表页**：物料列表 + 搜索栏 + 类型筛选 + 新增按钮
- **弹窗**：新增/编辑物料

### 列表页字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 物料编号 | 文本 | 系统自动生成，如 M001、M002 |
| 物料名称 | 文本 | 如：白色棉布、YKK拉链、四眼纽扣 |
| 类型 | 标签 | 原料（蓝色）/ 辅料（绿色） |
| 规格 | 文本 | 如：150cm门幅、5号、30cm |
| 单位 | 文本 | 如：米、条、个、卷 |
| 参考单价 | 数字 | 元/单位 |
| 默认供应商 | 文本 | 关联的供应商名称 |
| 操作 | 按钮 | 编辑、删除 |

### 新增/编辑弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 物料名称 | 文本 | 是 | |
| 类型 | 单选 | 是 | 原料 / 辅料 |
| 规格 | 文本 | 否 | |
| 单位 | 文本 | 是 | 如：米、条、个、卷 |
| 参考单价 | 数字 | 否 | 元/单位 |
| 默认供应商 | 下拉选择 | 否 | 关联供应商档案 |

### 操作功能

| 功能 | 说明 |
|------|------|
| 新增物料 | 打开弹窗填写信息，编号自动生成 |
| 编辑 | 修改物料信息 |
| 删除 | 删除该物料 |
| 类型筛选 | 按「原料/辅料」筛选物料列表 |
| 搜索 | 按物料名称模糊搜索 |

### 业务规则
- 物料编号由系统自动生成，格式为 M+三位数字（M001、M002...）
- 已被订单使用的物料**禁止删除**，提示「该物料已被订单使用，无法删除」
- 类型为固定选项：原料、辅料
- 款号标准物料清单中，可从物料库选择，也支持手动输入自定义物料
