# 模块7：权限管理 - 需求文档

## 概述

权限管理模块用于管理系统菜单、角色和功能权限。通过「菜单管理→角色管理→权限分配」三层结构，实现灵活的权限控制。支持页面级和操作级的权限粒度。

---

## 7.1 菜单管理

### 功能说明
管理系统中的所有菜单项，包括目录、页面和按钮。菜单数据动态管理，权限配置时从菜单管理中加载菜单树。

### 页面布局
- **列表页**：树形表格展示菜单结构 + 新增按钮

### 列表字段（树形表格）

| 字段 | 类型 | 说明 |
|------|------|------|
| 菜单名称 | 文本 | 如：基础配置、员工档案、新增按钮 |
| 所属平台 | 标签 | Web端（蓝色）/ 移动端（绿色） |
| 菜单类型 | 标签 | 目录（蓝色）/ 页面（绿色）/ 按钮（橙色） |
| 上级菜单 | 文本 | 父级菜单名称（顶级为空） |
| 路由地址 | 文本 | 页面路径（页面类型时填写） |
| 按钮标识 | 文本 | 如：add、edit、delete、audit（按钮类型时填写） |
| 图标 | 图标 | 菜单图标（目录/页面类型可选） |
| 排序 | 数字 | 显示顺序 |
| 状态 | 标签 | 启用（绿色）/ 停用（灰色） |
| 操作 | 按钮 | 编辑、新增子菜单、删除 |

### 新增/编辑菜单弹窗

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 所属平台 | 单选 | 是 | Web端 / 移动端 |
| 菜单类型 | 单选 | 是 | 目录 / 页面 / 按钮 |
| 上级菜单 | 下拉选择 | 否 | 顶级目录不选，选择后自动归入该菜单下 |
| 菜单名称 | 文本 | 是 | |
| 路由地址 | 文本 | 页面类型必填 | 前端页面路径，如 /employee/list |
| 按钮标识 | 文本 | 按钮类型必填 | 如 add、edit、delete、audit、export |
| 图标 | 选择 | 否 | 目录/页面类型可选图标 |
| 排序 | 数字 | 否 | 数字越小越靠前 |
| 状态 | 单选 | 是 | 启用/停用 |

### 菜单类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| 目录 | 菜单分组，可包含子菜单 | 基础配置、订单管理、裁床管理 |
| 页面 | 具体的功能页面 | 员工列表、订单列表 |
| 按钮 | 页面内的操作按钮 | 新增、编辑、删除、审核、导出 |

### 业务规则
- 只有管理员可以操作菜单管理
- 菜单支持多级目录嵌套（目录→目录→页面→按钮）
- 删除目录时，如有子菜单禁止删除，提示「该菜单下有子菜单，请先删除子菜单」
- 停用菜单后，该菜单对所有角色不可见
- 菜单修改后，权限配置页面实时同步

## 7.2 角色管理

### 功能说明
管理系统中的角色，每个角色关联一组权限。员工通过关联角色获得对应的系统权限。

### 页面布局
- **列表页**：角色列表 + 新增按钮
- **详情页**：角色信息 + 权限配置

### 角色列表页字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 角色名称 | 文本 | 如：报工角色、组长角色、财务角色 |
| 角色说明 | 文本 | |
| 包含员工数 | 数字 | 该角色下有多少员工 |
| 操作 | 按钮 | 编辑、配置权限、删除 |

### 新增/编辑角色弹窗

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 角色名称 | 文本 | 是 | |
| 角色说明 | 文本 | 否 | |

### 业务规则
- 系统预设角色不可删除（如：超级管理员）
- 有关联员工的角色不可删除，提示「该角色下有N名员工，请先转移员工」
- 新增角色默认无任何权限，需手动配置
- 只有管理员可以操作角色管理

## 7.3 权限配置

### 功能说明
为每个角色分配可访问的功能页面和可执行的操作。菜单树从菜单管理中动态加载。

### 页面布局
在角色详情页或点击「配置权限」进入权限配置页面。

### 权限配置页面交互

页面分两个Tab展示：

**Tab1：Web端权限**
- 展示Web端菜单树（从菜单管理动态加载，只显示所属平台为「Web端」且启用状态的菜单）
- 每个节点有勾选框
- 勾选父节点时，子节点自动全选
- 取消父节点时，子节点自动全取消
- 也可单独勾选某个子节点

**Tab2：移动端权限**
- 展示移动端菜单树（从菜单管理动态加载，只显示所属平台为「移动端」且启用状态的菜单）
- 交互方式同上

### 权限粒度

| 级别 | 说明 | 示例 |
|------|------|------|
| 目录级 | 控制菜单分组的可见性 | 能否看到「基础配置」菜单 |
| 页面级 | 控制功能页面的访问权限 | 能否进入「员工列表」页面 |
| 按钮级 | 控制页面内操作按钮的显示 | 能否点击「新增」「编辑」「删除」按钮 |

### 业务规则
- 勾选「页面」权限才能访问该页面
- 按钮权限需在「页面」权限基础上单独勾选
- 目录权限控制该目录下所有子菜单的可见性
- 超级管理员拥有全部权限（Web端+移动端），不可修改
- 权限修改后实时生效（用户刷新页面后）
- Web端和移动端的菜单统一在菜单管理中配置，通过「所属平台」字段区分
- 移动端菜单一般只到页面级，不涉及按钮级权限

## 7.4 预设角色

系统预设以下角色，不可删除，可修改权限：

| 角色 | Web端权限 | 移动端权限 | 说明 |
|------|----------|-----------|------|
| 超级管理员 | 全部 | 全部 | 系统最高权限，权限不可修改 |
| 报工角色 | 无 | 员工端全部功能 | 普通员工使用 |
| 裁床角色 | 裁床管理全部 | 员工端全部功能 | 裁床师傅使用 |
| 组长角色 | 管理后台-生产看板、异常处理、计时录入 | 管理员端全部功能 | 车间组长使用 |
| 财务角色 | 财务管理全部 + 管理后台-工资管理、报表中心 | 无 | 财务人员使用 |

管理员可在预设角色基础上修改权限，也可新增自定义角色。

## 与员工档案的关联

### 员工档案字段调整

员工档案中的「角色」字段改为下拉选择角色：

| 字段 | 类型 | 说明 |
|------|------|------|
| 角色 | 下拉选择 | 从角色管理中选择，一个员工只能有一个角色 |

### 业务规则
- 员工登录后，系统根据其角色加载对应的权限
- Web端登录：根据角色加载Web端权限，控制菜单显示、页面访问和操作按钮
- 移动端登录：根据角色加载移动端权限，展示对应的功能菜单
- 同一个员工可以在Web端和移动端拥有不同的权限范围
- 修改员工角色后，下次登录生效

## 模块总结

| 子模块 | 核心功能 |
|--------|---------|
| 菜单管理 | 动态管理Web端和移动端的目录/页面/按钮菜单，支持多级嵌套 |
| 角色管理 | 增删改查角色，查看角色下的员工 |
| 权限配置 | 从菜单管理动态加载菜单树，按平台（Web/移动）分别配置权限 |
| 预设角色 | 系统预设常用角色，不可删除，可修改权限 |

## 业务规则汇总

- 只有管理员可以操作菜单管理和角色管理
- 菜单修改后实时同步到权限配置页面
- 权限修改后用户刷新页面即可生效
- 超级管理员权限不可修改
- 有关联员工的角色不可删除
