# 模块4：移动端 - 需求文档

## 概述

移动端以微信小程序为载体，支持员工端和管理员端两种角色。登录后根据角色展示不同的功能菜单。采用免密登录方式，降低使用门槛。

---

## 4.1 登录

### 功能说明
移动端支持两种登录方式：员工登录（工号）和管理员登录（账号+密码），通过Tab切换。

### 登录页面设计

页面顶部有两个切换Tab：「员工登录」和「管理员登录」

#### 员工登录模式

| 元素 | 说明 |
|------|------|
| 工号输入框 | 输入工号，如 A001 |
| 登录按钮 | 点击验证并登录 |

**登录流程**：
1. 输入工号
2. 系统验证工号是否存在且状态为启用
3. 检查该员工角色是否有移动端权限
4. 验证通过，进入员工端主页

#### 管理员登录模式

| 元素 | 说明 |
|------|------|
| 账号输入框 | 输入登录账号 |
| 密码输入框 | 输入登录密码 |
| 登录按钮 | 点击验证并登录 |

**登录流程**：
1. 输入账号和密码
2. 系统验证账号密码是否正确且状态为启用
3. 检查该员工角色是否有移动端权限
4. 验证通过，进入管理员端主页

### 错误提示

| 情况 | 提示信息 |
|------|---------|
| 工号/账号不存在 | 「账号不存在」 |
| 密码错误 | 「密码错误」 |
| 账号已停用 | 「账号已停用，请联系管理员」 |
| 角色无移动端权限 | 「无权限，请联系管理员」 |

### 功能菜单加载

登录后，系统根据员工关联的角色（在「权限管理-角色管理」中配置）加载对应的功能菜单。

| 角色示例 | 可见功能 |
|---------|---------|
| 报工角色 | 扫码报工、我的工资、报工记录 |
| 裁床角色 | 裁床管理、扫码报工、我的工资、报工记录 |
| 组长角色 | 生产看板、异常预警、扎号查询、订单查询、计时录入 |
| 超级管理员 | 全部功能 |

### 业务规则
- 员工登录：输入工号即可登录，无需密码
- 管理员登录：输入账号+密码登录
- 登录账号和密码在「基础配置-员工档案」中设置
- 停用状态的员工无法登录
- 登录态长期有效（Token不过期或长期有效）
- 同一账号可在多台设备登录（不踢出其他设备）

### 4.2.2 扫码报工

#### 功能说明
工人扫描菲仔上的码，选择完成的工序，一键上报计件。支持两种码类型，系统自动识别。

#### 支持的码类型

| 码类型 | 说明 | 扫码后行为 |
|--------|------|-----------|
| 扎号QR码 | 每扎唯一的二维码 | 识别单个扎号，展示该扎的工序列表 |
| 床次条形码 | 同一床相同的条形码 | 识别整床所有扎号，展示扎号列表和工序列表，默认全选 |

#### 场景A：扫扎号QR码

**报工流程**：
1. 工人点击「扫码报工」
2. 调用手机摄像头扫描扎号QR码
3. 系统识别扎号，展示扎详情和工序列表
4. 工人勾选自己完成的工序（可多选）
5. 点击「确认上报」
6. 上报成功，展示本次报工的金额汇总

**扫码后展示信息**：

| 信息 | 说明 |
|------|------|
| 订单号 | |
| 款号 | |
| 颜色 | |
| 尺码 | |
| 扎号 | 如 1-001 |
| 件数 | 如 20件 |

**工序列表**：

| 工序 | 状态 | 可操作 |
|------|------|--------|
| 裁剪 | ✅ 已完成（张三） | 灰色不可选 |
| 车领 | ⬜ 未完成 | 可勾选 |
| 钉扣 | ⬜ 未完成 | 可勾选 |
| 质检 | ⬜ 未完成 | 可勾选 |

- 已完成的工序：灰色展示，显示报工人姓名，不可勾选
- 未完成的工序：可勾选，支持多选

---

#### 场景B：扫床次条形码

**报工流程**：
1. 工人点击「扫码报工」
2. 调用手机摄像头扫描床次条形码
3. 系统识别床次，展示该床所有扎号和工序列表
4. 默认全选所有扎号，工人可取消勾选部分扎号
5. 工人勾选自己完成的工序（可多选）
6. 点击「确认上报」
7. 上报成功，展示本次报工的金额汇总

**扫码后展示信息**：

| 信息 | 说明 |
|------|------|
| 订单号 | |
| 款号 | |
| 颜色 | |
| 尺码 | |
| 床次 | 如：第1床 |
| 总扎数 | 如：5扎 |

**扎号列表**（默认全选，可取消）：

| 扎号 | 件数 | 勾选 |
|------|------|------|
| 1-001 | 20件 | ✅ |
| 1-002 | 20件 | ✅ |
| 1-003 | 20件 | ✅ |
| 1-004 | 20件 | ✅ |
| 1-005 | 15件 | ✅ |

**工序列表**（可多选）：

| 工序 | 可操作 |
|------|--------|
| 裁剪 | 可勾选 |
| 车领 | 可勾选 |
| 钉扣 | 可勾选 |

**确认上报后展示**：

| 信息 | 说明 |
|------|------|
| 上报成功提示 | 如「上报成功」 |
| 本次上报汇总 | 如：车领 × 95件 × 0.5元 = 47.5元 |

---

#### 确认上报后展示（通用）

| 信息 | 说明 |
|------|------|
| 上报成功提示 | 如「上报成功」 |
| 本次上报汇总 | 如：车领 × 20件 × 0.5元 = 10元 |

#### 业务规则
- 系统自动识别码类型：扫扎号QR码走单扎逻辑，扫床次条形码走批量逻辑
- 扫床次条形码后默认全选所有扎号，工人可取消勾选部分扎号
- 工人一次可勾选多道工序，确认后批量上报
- 已完成的工序：灰色展示，不可勾选
- 上报成功后，该工序记录关联当前工人和当前时间
- 同一扎的同一工序不可重复上报（由系统状态控制）
- 同一扎的同一工序如已被其他工人报工，不可重复上报

### 4.2.3 我的工资

#### 功能说明
工人实时查看自己的计件工资情况。

#### 页面布局

**顶部汇总区**：

| 区域 | 内容 |
|------|------|
| 今日已赚 | 今日计件工资总额，大字展示 |
| 本月累计 | 本月计件工资总额 |

**工资明细列表**：

按日期分组，每天一个分组，展示当天的所有报工明细。

**每日分组标题**：
- 日期 + 当日小计金额

**每条明细字段**：

| 字段 | 说明 |
|------|------|
| 工序名称 | 如：车领 |
| 扎号 | 如：1-001 |
| 件数 | 如：20件 |
| 工价 | 如：0.5元/件 |
| 金额 | 如：10元（件数×工价） |

#### 业务规则
- 仅展示计件工资，计时工资暂不在员工端展示（预留数据结构）
- 工资明细区分计件和计时类型（计时部分先不展示）
- 金额根据报工记录实时计算：件数 × 订单工价
- 管理员清除误扫记录后，对应工资自动扣减，员工端实时反映

---

| 订单号 | 文本 | |
| 款号 | 文本 | |
| 扎号 | 文本 | 如：1-001 |
| 工序名称 | 文本 | 如：车领 |
| 件数 | 数字 | 如：20件 |
| 工价 | 数字 | 如：0.5元/件 |

- 金额 = 件数 × 工价

#### 功能说明

#### 筛选条件

| 筛选项 | 类型 | 默认值 |
|--------|------|--------|
| 状态 | 下拉 | 待处理 |

#### 预警列表字段

| 字段 | 说明 |
|------|------|
| 扎号 | 如：1-001 |
| 订单号 | |
| 异常描述 | 如：「车领」未完成，但「钉扣」已扫 |
| 报工人 | |
| 报工时间 | |
| 状态 | 待处理 / 已处理 |

#### 操作

| 操作 | 说明 |
|------|------|
| 忽略 | 确认是正常并行，填写原因，关闭预警 |
| 清除 | 跳转到清除页面，清除后置工序的报工记录 |
| 补录 | 跳转到补录页面，为前置工序补录 |

#### 清除操作页面

| 字段 | 类型 | 说明 |
|------|------|------|
| 报工信息 | 只读 | 扎号、工序、报工人、件数、时间 |
| 清除原因 | 文本输入 | 必填 |

- 扣减工人工资
- 释放该工序
- 若扎已封死则复活
- 记录操作日志

#### 补录操作页面

| 字段 | 类型 | 说明 |
|------|------|------|
| 扎号 | 只读 | 从预警带出 |
| 工序 | 下拉选择 | 只显示未完成的工序 |
| 工人 | 下拉选择 | |
| 件数 | 数字 | 默认等于该扎件数 |
| 报工时间 | 日期时间 | 默认当前时间 |

点击「确认补录」后执行：
- 创建报工记录
- 增加工人工资
- 记录操作日志

## 模块总结

### 员工端

| 子模块 | 核心功能 |
|--------|---------|
| 免密登录 | 输入登录码直接登录，长期有效 |
| 扫码报工 | 扫菲仔QR码，多选工序，一键上报 |
| 我的工资 | 今日/本月汇总，按日期分组的计件明细 |
| 我的报工记录 | 按日期筛选的历史报工明细，含工价和金额 |

### 管理员端

| 子模块 | 核心功能 |
|--------|---------|
| 生产看板 | 订单/工人维度进度查看，瓶颈工序高亮 |
| 异常预警 | 查看断层预警，支持忽略/清除/补录 |
| 计时录入 | 现场录入临时工计时工资 |
| 扎号查询 | 搜索/扫码查看扎号详情，支持清除/补录 |
| 订单查询 | 查看订单信息和进度 |

## 暂不实现

| 功能 | 说明 |
|------|------|
| 异常反馈 | 工人拍照上报质量问题，后续版本再加 |
| 计时工资展示 | 员工端暂不展示计时工资，预留数据结构 |
| 工资管理 | 管理员端暂不展示工资审核功能，仅在电脑端 |
| 财务报表 | 仅在电脑端 |
