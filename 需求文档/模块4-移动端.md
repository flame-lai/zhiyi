# 模块4：移动端 - 需求文档

## 概述

移动端以微信小程序为载体，支持员工端和管理员端两种角色。登录后根据角色展示不同的功能菜单。统一使用工号+密码登录。

---

## 4.1 登录

### 功能说明
移动端统一使用**工号 + 密码**登录，不再区分员工登录和管理员登录。

### 登录页面设计

| 元素 | 说明 |
|------|------|
| 工号输入框 | 输入工号，如 A001 |
| 密码输入框 | 输入登录密码 |
| 登录按钮 | 点击验证并登录 |

**登录流程**：
1. 输入工号和密码
2. 系统验证工号是否存在且密码正确
3. 检查账号状态是否为启用
4. 验证通过，根据角色进入对应主页

### 错误提示

| 情况 | 提示信息 |
|------|---------|
| 工号不存在 | 「账号不存在」 |
| 密码错误 | 「密码错误」 |
| 账号已停用 | 「账号已停用，请联系管理员」 |

### 功能菜单加载

登录后，系统根据员工关联的角色（在「权限管理-角色管理」中配置）加载对应的功能菜单。

| 角色示例 | 可见功能 |
|---------|---------|
| 报工角色 | 扫码报工、我的工资、报工记录 |
| 裁床角色 | 裁床管理、扫码报工、我的工资、报工记录 |
| 组长角色 | 生产看板、异常预警、扎号查询、订单查询、计时录入、员工管理 |
| 超级管理员 | 全部功能 |

### 业务规则
- 统一使用工号+密码登录，初始密码为 123456
- 登录账号默认等于工号，在「基础配置-员工档案」中设置
- 停用状态的员工无法登录
- 登录态长期有效（Token不过期或长期有效）
- 同一账号可在多台设备登录（不踢出其他设备）
- 员工可在「我的」→「个人中心」→「修改密码」中自行修改密码

### 4.2.2 扫码报工

#### 功能说明
工人扫描菲仔上的码，选择完成的工序，一键上报计件。支持两种码类型，系统自动识别。

#### 支持的码类型

| 码类型 | 说明 | 扫码后行为 |
|--------|------|-----------|
| 扎号QR码 | 每扎唯一的二维码 | 识别单个扎号，展示该扎的工序列表 |
| 床次条形码 | 同一床相同的条形码 | 识别整床所有扎号，展示扎号列表和工序列表，默认全选 |

#### 场景A：扫扎号QR码

**报工流程**：
1. 工人点击「扫码报工」
2. 调用手机摄像头扫描扎号QR码
3. 系统识别扎号，展示扎详情和工序列表
4. 工人勾选自己完成的工序（可多选）
5. 点击「确认上报」
6. 上报成功，展示本次报工的金额汇总

**扫码后展示信息**：

| 信息 | 说明 |
|------|------|
| 订单号 | |
| 款号 | |
| 颜色 | |
| 尺码 | |
| 扎号 | 如 1-001 |
| 件数 | 如 20件 |

**工序列表**：

| 工序 | 状态 | 可操作 |
|------|------|--------|
| 裁剪 | ✅ 已完成（张三） | 灰色不可选 |
| 车领 | ⬜ 未完成 | 可勾选 |
| 钉扣 | ⬜ 未完成 | 可勾选 |
| 质检 | ⬜ 未完成 | 可勾选 |

- 已完成的工序：灰色展示，显示报工人姓名，不可勾选
- 未完成的工序：可勾选，支持多选

---

#### 场景B：扫床次条形码

**报工流程**：
1. 工人点击「扫码报工」
2. 调用手机摄像头扫描床次条形码
3. 系统识别床次，展示该床颜色尺码汇总和工序列表
4. 默认全选所有颜色尺码，工人可取消勾选部分
5. 工人勾选自己完成的工序（可多选）
6. 点击「确认上报」
7. 上报成功，自动返回扫码页面准备下次扫码

**扫码后展示信息**：

| 信息 | 说明 |
|------|------|
| 订单号 | |
| 款号 | |
| 床次 | 如：第1床 |
| 总数量 | 如：95件（成衣件数） |
| 颜色尺码 | 汇总标签，如：白M: 20件 黑M: 10件 |

**颜色尺码选择**（默认全选，可取消）：

| 颜色尺码 | 件数 | 勾选 |
|----------|------|------|
| 白 M | 20件 | ✅ |
| 白 L | 20件 | ✅ |
| 黑 M | 10件 | ✅ |

**工序列表**（可多选，受批量上报控制）：

| 工序 | 状态 | 可操作 |
|------|------|--------|
| 裁剪 | ⬜ 未完成 | 可勾选 |
| 车领 | ⬜ 未完成 | 不支持批量上报（置灰） |
| 钉扣 | ⬜ 未完成 | 可勾选 |

**业务规则**：
- 颜色尺码数量按物理扎去重计算（同一扎号多部位只计一次）
- 工序是否支持批量上报由后台款号工序的「批量上报」字段控制
- 不支持批量上报的工序置灰不可选，显示「不支持批量上报」提示

---

#### 确认上报后展示（通用）

| 信息 | 说明 |
|------|------|
| 上报成功提示 | 如「上报成功」 |
| 本次上报汇总 | 如：车领 × 20件 × 0.5元 = 10元 |

#### 业务规则
- 系统自动识别码类型：扫扎号QR码走单扎逻辑，扫床次条形码走批量逻辑
- 扫床次条形码后默认全选所有扎号，工人可取消勾选部分扎号
- 工人一次可勾选多道工序，确认后批量上报
- 已完成的工序：灰色展示，不可勾选
- 上报成功后，该工序记录关联当前工人和当前时间
- 同一扎的同一工序不可重复上报（由系统状态控制）
- 同一扎的同一工序如已被其他工人报工，不可重复上报

### 4.2.3 我的工资

#### 功能说明
工人查看自己的计件工资情况，按款号维度汇总，支持日期筛选。

#### 日期筛选

| 筛选项 | 说明 |
|--------|------|
| 今日 | 默认选中，显示今日数据 |
| 本月 | 显示本月数据 |
| 自定义 | 选择开始和结束日期 |

#### 汇总卡片

| 区域 | 说明 |
|------|------|
| 总数量 | 筛选日期内的总报工件数 |
| 总收入 | 仅包含已公开工价的款号金额 |

#### 款号汇总列表

按款号分组展示，每个款号显示：

| 信息 | 说明 |
|------|------|
| 款号 | 如：M001 |
| 总件数 | 该款号的总报工件数 |
| 总金额 | 该款号的总工资（隐藏工价的显示 `-`） |

**工序明细**（每个款号下展示）：

| 工序 | 件数 | 单价 | 金额 |
|------|------|------|------|
| 裁剪 | 5件 | ×0.50 | ¥2.50 |
| 包装 | 5件 | ×0.10 | ¥0.50 |

#### 工价隐藏规则
- 如果某款号在后台设置了「移动端隐藏工价」，则该款号的单价和金额显示为 `-`
- 总收入仅统计已公开工价的款号
- 如有隐藏款号，页面显示提示：「* 部分款号工价未公开，合计仅含已公开部分」

#### 业务规则
- 金额根据报工记录实时计算：件数 × 订单工价
- 管理员清除误扫记录后，对应工资自动扣减，员工端实时反映

### 4.3.5 补录报工（独立功能）

#### 功能说明
管理员可为任意员工、扎号、工序补录报工记录。

#### 页面布局

| 字段 | 类型 | 说明 |
|------|------|------|
| 工号 | 文本输入 | 输入员工工号 |
| 扎号/条码 | 扫码或输入 | 点击扫码图标自动识别，或手动输入 |
| 工序 | 选择 | 扫码后自动列出可选工序 |
| 数量 | 数字 | 默认等于扎号件数，可修改 |

#### 扫码流程
1. 点击扫码图标

4. 自动列出可选工序（已报工的工序标记不可选）

#### 业务规则
- 工号按员工工号查找，不存在则提示
- 补录的报工记录 reportType=3，supplementFlag=1

### 4.3.10 款号工序控制

#### 批量上报控制

在后台「款号管理」的工序路由中，每个工序有「批量上报」开关：

| 设置 | 扫床次码报工时的行为 |
|------|---------------------|
| 开启（默认） | 该工序可勾选上报 |
| 关闭 | 该工序置灰，显示「不支持批量上报」 |

**业务场景**：某些工序（如质检）不适合批量上报，需要逐扎操作。

#### 移动端工价显示控制

在后台「款号管理」的基本信息中，有「移动端显示工价」开关：

| 设置 | 移动端行为 |
|------|-----------|
| 开启（默认） | 正常显示工价和金额 |
| 关闭 | 工价显示为 `-`，金额显示为 `-` |

**影响范围**：
- 扫码报工页面：工序工价显示为 `- 元/件`
- 工资汇总页面：该款号的单价和金额显示为 `-`
- 报工记录页面：单价和金额显示为 `-`
- 总收入仅统计已公开工价的款号

## 模块总结

### 员工端

| 子模块 | 核心功能 |
|--------|---------|
| 工号密码登录 | 统一使用工号+密码登录，初始密码123456 |
| 扫码报工 | 扫扎号码或裁床码，选择工序一键上报 |
| 我的工资 | 按款号汇总，支持日期筛选，含工序明细 |
| 我的报工记录 | 按日期筛选的历史报工明细 |
| 修改密码 | 在「我的」→「个人中心」中修改密码 |

### 管理员端

| 子模块 | 核心功能 |
|--------|---------|
| 生产看板 | 订单/工人维度进度查看，瓶颈工序高亮 |
| 异常预警 | 查看断层预警，支持忽略/清除/补录 |
| 清除报工 | 搜索/扫码查找报工记录并清除 |
| 补录报工 | 输入工号、扫码选扎号、选工序、提交补录 |
| 计时录入 | 输入工号，现场录入临时工计时工资 |
| 员工管理 | 查询、新增、编辑、启停用、删除员工 |
| 扎号查询 | 搜索/扫码查看扎号详情 |
| 订单查询 | 查看订单信息和进度 |

### 后台配置项

| 配置 | 位置 | 说明 |
|------|------|------|
| 批量上报 | 款号管理 → 工序路由 | 控制工序是否支持扫裁床码批量上报 |
| 移动端显示工价 | 款号管理 → 基本信息 | 控制移动端是否显示该款号的工价 |
