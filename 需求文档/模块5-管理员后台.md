# 模块5：组长/管理员后台 - 需求文档

## 概述

管理员后台是管理者的核心工作台，包含生产进度看板、异常处理、计时工资录入、工资管理和报表中心。供组长、管理员、财务等角色使用。

---

## 5.2 进度断层预警

### 功能说明
集成在看板页面中，自动检测「前置工序未完成，后置工序已扫」的情况。仅作为提示，管理员自行判断是异常还是正常并行操作。

### 预警规则
按照订单中工序的排列顺序，如果第N道工序已完成，但第N-1道工序未完成，则标记为断层预警。

### 预警列表

| 字段 | 类型 | 说明 |
|------|------|------|
| 扎号 | 文本 | 如：1-001 |
| 订单号 | 文本 | |
| 款号 | 文本 | |
| 异常描述 | 文本 | 如：「车领」未完成，但「钉扣」已扫 |
| 前置工序 | 文本 | 未完成的工序 |
| 后置工序 | 文本 | 已完成的工序 |
| 报工人 | 文本 | 后置工序的报工人 |
| 报工时间 | 日期时间 | |
| 状态 | 标签 | 待处理 / 已忽略 / 已清除 / 已补录 |
| 操作 | 按钮 | 忽略、清除后置、补录前置 |

### 管理员操作

| 操作 | 说明 | 系统行为 |
|------|------|---------|
| 忽略 | 确认是正常并行操作 | 记录处理结果，关闭预警 |
| 清除后置工序 | 认为是误扫 | 跳转到清除页面，清除该报工记录 |
| 补录前置工序 | 前置工序漏扫 | 跳转到补录页面，为漏扫的前置工序补录 |

### 处理记录

| 字段 | 说明 |
|------|------|
| 预警内容 | 如：「车领」未完成，但「钉扣」已扫 |
| 处理方式 | 忽略 / 清除后置 / 补录前置 |
| 处理人 | 管理员姓名 |
| 处理时间 | |
| 备注 | 处理原因说明 |

### 业务规则
- 预警默认按时间倒序排列，待处理的置顶
- 支持筛选：待处理 / 已处理 / 全部
- 每条预警处理后不可撤回，但可查看处理历史

## 5.3 管理员改错（清除/补录）

### 功能说明
管理员清除误扫记录或为漏扫的工人补录工序。提供两个操作入口。

### 入口1：异常处理页面
- 汇集所有待处理的断层预警
- 从预警列表一键跳转到清除或补录操作
- 适合日常巡查、批量处理

### 入口2：扎号详情页
- 在扎号详情的工序列表中，每道已完成的工序旁边有「清除」按钮
- 在扎号详情中也可以直接「补录」某道工序
- 适合已定位到某个扎号时直接操作

---

### A. 错误清除

#### 操作流程
1. 管理员找到需要清除的报工记录（从预警跳转或手动搜索扎号）
2. 点击「清除」按钮
3. 弹出确认弹窗，填写清除原因
4. 确认清除

#### 确认弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 报工信息 | 只读 | - | 展示：扎号、工序、报工人、件数、时间 |
| 清除原因 | 文本 | 是 | 如：「工人扫错工序」 |

#### 系统执行逻辑
1. 将该报工记录状态改为「已清除」
2. 扣减该工人的计件工资
3. 释放该工序（状态变回未完成）
4. 若该扎所有工序已完成（已封死），则状态变回「生产中」，QR码复活
5. 记录操作日志（操作人、时间、原因）

---

### B. 手工补录

#### 操作流程
1. 管理员选择扎号（搜索或从预警跳转）
2. 选择要补录的工序
3. 选择报工的工人
4. 填写件数（默认等于该扎件数）
5. 填写报工时间（默认当前时间，可手动修改）
6. 确认补录

#### 补录弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 扎号 | 搜索选择 | 是 | |
| 工序 | 下拉选择 | 是 | 只显示该扎未完成的工序 |
| 工人 | 下拉选择 | 是 | |
| 件数 | 数字 | 是 | 默认等于该扎件数 |
| 报工时间 | 日期时间 | 否 | 默认当前时间，可手动修改 |

#### 系统执行逻辑
1. 创建一条新的报工记录（标记为「补录」）
2. 增加该工人的计件工资
3. 标记该工序为已完成
4. 若所有工序完成，扎状态变为「已完成」，QR码失效
5. 记录操作日志

### 批量新增弹窗

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 日期 | 日期 | 是 | 同一天 |
| 时薪 | 数字 | 是 | 所有人统一时薪 |
| 工人列表 | 多选 | 是 | 选择多个工人 |

- 金额自动计算：工时×时薪，不可手动修改
- 时薪每次手动填写，不预设默认值
- 支持编辑和删除已录入的记录
- 批量新增时，默认所有人相同工时和时薪，可逐人修改
