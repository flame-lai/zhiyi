# 模块6：财务模块 - 需求文档

## 概述

财务模块负责订单成本核算、收入管理、利润分析和工资发放。目前仅核算人工成本，物料成本和应付账款后续版本增加。

---

## 6.1 订单成本核算

### 功能说明
核算每个订单的人工成本，包括计件工资和手动关联的计时工资。

### 页面布局
- **列表页**：订单成本列表 + 筛选栏

### 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 订单号 | 下拉/搜索 | |
| 款号 | 下拉/搜索 | |
| 日期范围 | 日期选择器 | |

### 列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 订单号 | 文本 | |
| 款号 | 文本 | |
| 计件成本 | 数字 | 该订单所有报工的计件工资合计，自动汇总 |
| 计时成本 | 数字 | 手动关联到该订单的计时工资合计 |
| 人工成本合计 | 数字 | 计件成本 + 计时成本 |

### 计时工资关联

点击某订单的「计时成本」列，弹出关联管理弹窗：

| 功能 | 说明 |
|------|------|
| 关联计时记录 | 从已有的计时工资记录中选择，关联到当前订单 |
| 取消关联 | 取消某条计时记录与当前订单的关联 |
| 查看明细 | 查看已关联的计时记录列表 |

### 业务规则
- 计件成本自动汇总：根据该订单下所有有效报工记录的金额合计
- 计时成本手动关联：从计时工资录入模块中选择记录关联到订单
- 一条计时记录只能关联一个订单
- 管理员清除报工记录后，计件成本自动更新

## 6.2 订单收入管理

### 功能说明
管理每个订单的收入金额和收款记录，支持部分收款。同时承担应收账款管理功能。

### 页面布局
- **列表页**：订单收入列表 + 筛选栏

### 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 订单号 | 下拉/搜索 | |
| 客户 | 下拉选择 | |
| 收款状态 | 下拉 | 未收齐 / 已收齐 |

### 列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 订单号 | 文本 | |
| 客户 | 文本 | |
| 订单金额 | 数字 | 从订单头带出，可在此处单独修改 |
| 已收金额 | 数字 | 汇总该订单所有收款记录 |
| 未收金额 | 数字 | 订单金额 - 已收金额 |
| 收款进度 | 进度条+百分比 | 已收金额 / 订单金额 |
| 操作 | 按钮 | 添加收款、查看收款记录、修改订单金额 |

### 修改订单金额

点击「修改订单金额」，弹出弹窗：

| 字段 | 类型 | 说明 |
|------|------|------|
| 原订单金额 | 只读 | 展示原金额 |
| 新订单金额 | 数字 | 手动输入 |
| 修改原因 | 文本 | |

### 收款记录管理

点击「查看收款记录」或「添加收款」，弹出收款管理弹窗：

#### 收款记录列表

| 字段 | 类型 | 说明 |
|------|------|------|
| 收款日期 | 日期 | |
| 收款金额 | 数字 | |
| 备注 | 文本 | 如：首付款、尾款、质保金 |
| 录入人 | 文本 | |
| 录入时间 | 日期时间 | |
| 操作 | 按钮 | 编辑、删除 |

#### 添加收款弹窗

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 收款日期 | 日期 | 是 | 默认今天 |
| 收款金额 | 数字 | 是 | |
| 备注 | 文本 | 否 | 如：首付款、尾款 |

### 业务规则
- 订单金额可在财务模块单独修改，修改不影响订单头的金额
- 已收金额自动汇总所有收款记录
- 未收金额 = 订单金额 - 已收金额
- 当未收金额 = 0 时，收款状态为「已收齐」
- 支持部分收款，一个订单可分多次添加收款记录
- 收款记录支持编辑和删除

## 6.3 订单利润分析

### 功能说明
计算每个订单的利润，支持按时间维度汇总。

### 页面布局
- **列表页**：订单利润列表 + 筛选栏 + 汇总统计

### 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 订单号 | 下拉/搜索 | |
| 客户 | 下拉选择 | |
| 日期范围 | 日期选择器 | |
| 汇总维度 | 下拉 | 按订单 / 按月 / 按季度 |

### A. 按订单维度

#### 列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 订单号 | 文本 | |
| 客户 | 文本 | |
| 订单金额（收入） | 数字 | |
| 人工成本 | 数字 | 计件+计时 |
| 利润 | 数字 | 收入 - 人工成本 |
| 利润率 | 百分比 | 利润 / 收入 × 100% |

### B. 按月维度

#### 列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 月份 | 文本 | 如：2024-01 |
| 订单数 | 数字 | 该月涉及的订单数 |
| 收入合计 | 数字 | |
| 成本合计 | 数字 | |
| 利润合计 | 数字 | |
| 平均利润率 | 百分比 | |

### C. 按季度维度

#### 列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 季度 | 文本 | 如：2024-Q1 |
| 订单数 | 数字 | |
| 收入合计 | 数字 | |
| 成本合计 | 数字 | |
| 利润合计 | 数字 | |
| 平均利润率 | 百分比 | |

### 汇总统计（页面顶部）

| 指标 | 说明 |
|------|------|
| 筛选范围内的收入合计 | |
| 筛选范围内的成本合计 | |
| 筛选范围内的利润合计 | |
| 平均利润率 | |

### 业务规则
- 利润 = 订单金额（收入） - 人工成本（计件+计时）
- 人工成本中只包含已审核/已发放状态的工资数据
- 利润率 = 利润 / 收入 × 100%
- 按月/季度汇总时，以订单的创建日期或完工日期为准（可配置）

## 6.4 工资结算

### 功能说明
财务办理实际工资发放，记录发放信息。与模块5的「工资管理」配合：
- 模块5：管理员确认工资数据（审核流程：待审核→已审核）
- 模块6：财务办理发放（已审核→已发放）

### 页面布局
- **列表页**：待发放工资列表 + 筛选栏

### 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 月份 | 月份选择器 | |
| 工人 | 下拉选择 | |
| 状态 | 下拉 | 待发放 / 已发放 / 全部 |

### 列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 工号 | 文本 | |
| 姓名 | 文本 | |
| 月份 | 文本 | |
| 应发合计 | 数字 | 从工资管理带出（计件+计时+其他） |
| 实发金额 | 数字 | 财务填写，可与应发不同 |
| 差额 | 数字 | 应发 - 实发 |
| 发放日期 | 日期 | |
| 发放方式 | 文本 | 如：银行转账、现金 |
| 状态 | 标签 | 待发放（灰）/ 已发放（绿） |
| 操作 | 按钮 | 办理发放 |

### 办理发放弹窗

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 应发合计 | 只读 | - | 展示应发金额 |
| 实发金额 | 数字 | 是 | 默认等于应发，可修改 |
| 差额原因 | 文本 | 否 | 如：借支抵扣、个税扣除 |
| 发放日期 | 日期 | 是 | 默认今天 |
| 发放方式 | 下拉 | 是 | 银行转账 / 现金 / 其他 |

### 业务规则
- 只有「已审核」状态的工资才能办理发放
- 实发金额可以与应发金额不同，需填写差额原因
- 办理发放后状态变为「已发放」
- 已发放的记录不可再修改
- 发放后更新工资管理中的状态

## 6.5 财务报表

### 功能说明
月度/年度收支和利润报表。

### A. 月度收支表

#### 筛选条件
- 年份、月份

#### 展示内容

| 项目 | 说明 |
|------|------|
| 期数 | 如：2024-01 |
| 收入 | 该月收款合计 |
| 支出-工资 | 该月工资发放合计 |
| 结余 | 收入 - 支出 |

#### 明细展开
点击某月可展开查看：
- 收入明细：各订单的收款记录
- 支出明细：各工人的工资发放记录

### B. 年度收支表

#### 筛选条件
- 年份

#### 展示内容

| 月份 | 收入 | 支出 | 结余 |
|------|------|------|------|
| 1月 | | | |
| 2月 | | | |
| ... | | | |
| 12月 | | | |
| **合计** | | | |

支持柱状图/折线图展示趋势。

### C. 订单利润汇总

#### 筛选条件
- 日期范围、汇总维度（月/季度）

#### 展示内容
复用6.3的按月/按季度汇总数据。

### 业务规则
- 收入数据来源于收款记录
- 支出数据来源于工资发放记录（目前仅工资，后续增加其他支出）
- 报表支持导出Excel
- 支持图表展示趋势

---

## 模块总结

| 子模块 | 核心功能 |
|--------|---------|
| 订单成本核算 | 计件成本自动汇总，计时成本手动关联到订单 |
| 订单收入管理 | 订单金额可修改，支持部分收款，承担应收账款管理 |
| 订单利润分析 | 利润=收入-人工成本，支持按订单/月/季度汇总 |
| 工资结算 | 已审核工资办理发放，支持实发与应发不同 |
| 财务报表 | 月度收支表、年度收支表、订单利润汇总 |

## 暂不实现

| 功能 | 说明 |
|------|------|
| 物料成本核算 | 物料暂只做清单，不核算成本 |
| 应付账款管理 | 等后续增加物料采购时再做 |
| 其他支出记录 | 如物料采购、租金等，后续增加 |
