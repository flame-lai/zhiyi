# 模块3：裁床与开菲 - 需求文档

## 概述

裁床与开菲模块负责将订单明细行拆分为扎号，生成并打印菲仔二维码，管理扎号的生产状态。裁剪作为第一道工序，裁床师傅通过扫裁床条形码完成裁剪报工。

---

## 3.1 裁床计划

### 功能说明
管理每笔订单明细行的裁床计划，支持分多床裁剪。独立页面，不嵌套在订单详情中。

### 页面布局
- **列表页**：裁床计划列表 + 筛选栏 + 新增按钮
- **弹窗**：新增/编辑裁床计划

### 筛选条件

| 筛选项 | 说明 |
|--------|------|
| 订单号 | 搜索/下拉选择 |
| 款号 | 搜索/下拉选择 |
| 颜色 | |
| 尺码 | |

### 列表页字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 订单号 | 文本 | 关联的订单 |
| 款号 | 文本 | |
| 颜色 | 文本 | |
| 尺码 | 文本 | |
| 床次 | 数字 | 第1床、第2床... |
| 计划件数 | 数字 | 手动输入 |
| 实际件数 | 数字 | 裁完后录入 |
| 每扎件数 | 数字 | 本床分扎规则 |
| 扎数 | 数字 | 系统自动计算 |
| 裁床条形码 | 文本+操作 | 展示条形码，支持「打印」 |
| 裁床日期 | 日期 | |
| 状态 | 标签 | 待裁剪 / 已裁剪 / 已开菲 / 已报工 |
| 操作 | 按钮 | 编辑、删除、录入实际数、开菲、打印裁床码 |

### 新增裁床计划弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 订单号 | 下拉选择 | 是 | 选择要裁的订单 |
| 订单明细行 | 下拉选择 | 是 | 选择具体的款号+颜色+尺码 |
| 床次 | 数字 | 是 | 手动输入，如 1、2、3 |
| 计划件数 | 数字 | 是 | 本床计划裁多少件 |
| 每扎件数 | 数字 | 是 | 本床的分扎规则，如 20 |
| 裁床日期 | 日期 | 否 | 默认今天 |

### 操作功能

| 功能 | 说明 |
|------|------|
| 新增 | 创建裁床计划，系统自动生成裁床条形码 |
| 编辑 | 修改计划信息 |
| 删除 | 删除裁床计划 |
| 录入实际数 | 录入裁床实际产出件数，录入后可修改 |
| 开菲 | 录入实际数后可执行开菲，系统自动分扎并生成扎号 |
| 打印裁床码 | 打印裁床条形码（开菲前即可打印） |

### 业务规则
- 每床的每扎件数单独设置，不使用全局默认值
- 尾扎不足一扎时，单独成扎（如95件，每扎20件 → 5扎，最后一扎15件）
- 创建裁床计划时系统自动生成裁床条形码，可立即打印
- 开菲后状态变为「已开菲」，扎号生成，可打印菲仔
- 已开菲的裁床计划不可删除

## 3.2 裁床条形码

### 功能说明
每个裁床计划生成一个裁床条形码，裁床师傅扫码完成裁剪工序报工。裁床条形码与菲仔一起打印，同一床所有菲仔共享相同的裁床条形码。

### 裁床条形码内容

```json
{
  "type": "cutting",
  "orderId": "ORD20240101001",
  "styleCode": "SP-001",
  "color": "红色",
  "size": "M",
  "bedNo": 1
}
```

### 打印方式
- 创建裁床计划后即可打印裁床条形码
- 与菲仔一起打印：每个菲仔标签上同时包含裁床条形码和扎号QR码
- 也可单独打印裁床条形码

### 裁床师傅报工流程
1. 裁床师傅裁完布料
2. 管理员录入实际件数并执行开菲
3. 打印菲仔（含裁床条形码和扎号QR码）
4. 裁床师傅扫任意一张菲仔上的裁床条形码
5. 系统识别当前登录用户，自动为该床所有扎号完成「裁剪」工序
6. 裁剪计件工资自动计算：实际件数 × 裁剪工价

### 业务规则
- 裁床师傅通过登录状态自动识别（扫裁床码时必须已登录）
- 裁床码只有在开菲后才能扫码报工（开菲前扫码提示「请先开菲」）
- 一个裁床计划对应一个裁床码，同一床所有菲仔的裁床码相同
- 扫裁床码后，该床所有扎号的「裁剪」工序自动完成，报工人记录为当前登录用户
- 同一裁床码不可重复扫码报工（提示「该床已报工」）

## 3.3 裁床实际数录入

### 功能说明
裁床师傅裁剪完毕后，录入实际产出件数。

### 交互方式
在裁床计划列表中，点击某条记录的「录入实际数」按钮，弹出弹窗。

### 弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 计划件数 | 数字 | 只读 | 展示计划数供参考 |
| 实际件数 | 数字 | 是 | 手动输入 |
| 裁床日期 | 日期 | 否 | 默认今天，可修改 |

### 业务规则
- 不做溢短限制，实际件数可自由录入
- 录入后可再次修改
- 录入实际件数后，可执行「开菲」操作

---

## 3.4 自动分扎

### 功能说明
执行开菲时，系统根据实际件数和每扎件数自动拆分扎号。

### 扎号格式

**格式**：`床次-序号`

**示例**：第1床裁了95件，每扎20件

| 扎号 | 件数 |
|------|------|
| 1-001 | 20件 |
| 1-002 | 20件 |
| 1-003 | 20件 |
| 1-004 | 20件 |
| 1-005 | 15件 |

### 全局唯一标识
系统内部使用 `订单号-扎号` 作为全局唯一标识，如 `ORD20240101001-1-001`

### 分扎逻辑

```
总扎数 = 向上取整(实际件数 / 每扎件数)
前N-1扎 = 每扎件数
最后一扎 = 实际件数 - (总扎数-1) × 每扎件数
```

### 业务规则
- 开菲后自动生成扎号，扎号不可手动修改
- 尾扎单独一扎，即使只有1件
- 开菲后自动变更订单状态为「生产中」

---

## 3.5 菲仔打印

### 功能说明
分扎完成后，生成并打印菲仔标签。每个菲仔标签包含两个码：裁床条形码和扎号QR码。

### 菲仔标签内容

| 信息 | 说明 |
|------|------|
| 订单号 | |
| 款号 | |
| 颜色 | |
| 尺码 | |
| 扎号 | 如 1-001 |
| 件数 | 如 20件 |
| 裁床条形码 | 同一床相同，裁床师傅扫码报工用 |
| 扎号QR码 | 每扎唯一，其他工人扫码报工用 |

### 菲仔标签布局示例

```
┌─────────────────────────────┐
│ 订单号：ORD20240101001       │
│ 款号：SP-001    颜色：红色    │
│ 尺码：M        扎号：1-001    │
│ 件数：20件                   │
│                             │
│ ┌───────┐    ┌───────┐      │
│ │ 裁床码  │    │ 扎号码  │      │
│ │(条形码) │    │ (QR码) │      │
│ └───────┘    └───────┘      │
│                             │
└─────────────────────────────┘
```

### 扎号QR码内容

```json
{
  "orderId": "ORD20240101001",
  "styleCode": "SP-001",
  "color": "红色",
  "size": "M",
  "bundleNo": "1-001",
  "qty": 20
}
```

### 打印功能

| 功能 | 说明 |
|------|------|
| 单扎打印 | 选择某一个扎，打印单张菲仔 |
| 批量打印 | 选择当前床次或当前订单，批量打印所有扎仔 |
| 重新打印 | 某扎菲仔丢失或损坏时，重新打印（不影响扎号和生产数据） |
| 打印裁床码 | 单独打印裁床条形码 |

### 打印配置

| 配置项 | 说明 |
|--------|------|
| 打印机类型 | 条码打印机（热敏打印机） |
| 标签尺寸 | 支持自定义，默认 60mm×40mm |
| 打印模板 | 菲仔标签的布局模板 |

### 业务规则
- 菲仔打印不限次数，重打不影响任何数据
- 每个菲仔包含两个码：裁床条形码（同一床相同）和扎号QR码（每扎唯一）
- 打印时自动调用本地条码打印机驱动
- 创建裁床计划后即可打印裁床码，开菲后可打印完整菲仔（含两个码）

## 3.6 扎号管理

### 功能说明
管理所有扎号的状态和信息，支持搜索和筛选。

### 页面布局
- **列表页**：扎号列表 + 搜索栏 + 筛选条件
- **详情页**：扎号完整信息 + 工序完成状态 + 操作历史

### 搜索与筛选

| 条件 | 类型 | 说明 |
|------|------|------|
| 扎号搜索 | 文本输入 | 按扎号精确或模糊搜索 |
| 订单号 | 下拉/搜索 | 筛选某订单下的扎号 |
| 款号 | 下拉/搜索 | 筛选某款号下的扎号 |
| 状态 | 下拉选择 | 生产中 / 已完成 |

### 列表页字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 扎号 | 文本 | 如 1-001 |
| 订单号 | 文本 | |
| 款号 | 文本 | |
| 颜色 | 文本 | |
| 尺码 | 文本 | |
| 件数 | 数字 | |
| 床次 | 数字 | |
| 状态 | 标签 | 生产中（橙色）/ 已完成（绿色） |
| 完成进度 | 文本 | 如 3/5（已完成3道工序/共5道） |
| 操作 | 按钮 | 查看详情、重新打印菲仔 |

### 扎号详情页

#### 基本信息
- 订单号、款号、颜色、尺码、件数、床次、扎号、状态

#### 工序完成状态

| 工序 | 状态 | 报工人 | 报工时间 |
|------|------|--------|---------|
| 裁剪 | ✅ 已完成 | 张三（裁床码扫码） | 2024-01-15 09:30 |
| 车领 | ✅ 已完成 | 李四（扎号码扫码） | 2024-01-15 14:20 |
| 钉扣 | ❌ 未完成 | - | - |
| 质检 | ❌ 未完成 | - | - |

#### 操作历史

| 时间 | 操作 | 操作人 | 说明 |
|------|------|--------|------|
| 2024-01-15 09:30 | 裁剪报工 | 张三 | 扫裁床码，完成整床裁剪 |
| 2024-01-15 14:20 | 报工 | 李四 | 完成「车领」工序 |
| 2024-01-16 10:00 | 清除 | 管理员 | 清除李四「车领」误扫记录 |

### 状态定义与流转

| 状态 | 说明 | 触发条件 |
|------|------|---------|
| 生产中 | 尚有工序未完成 | 开菲后默认状态 |
| 已完成 | 全部工序完成 | 所有工序都有有效报工记录 |

#### 状态流转

| 操作 | 状态变化 |
|------|---------|
| 开菲 | → 生产中 |
| 最后一道工序报工 | → 已完成，QR码自动失效 |
| 管理员清除某道工序的报工记录 | 已完成 → 生产中，QR码复活 |

### 业务规则
- 扎号由系统自动生成，不可手动修改
- 「已完成」状态的扎号，QR码自动失效，工人扫码提示「该扎已全部完成」
- 管理员清除误扫记录后，该扎状态变回「生产中」，QR码自动复活
- 扎号详情页可查看完整的报工历史和操作记录

## 模块总结

| 子模块 | 核心功能 |
|--------|---------|
| 裁床计划 | 管理裁床计划，支持多床裁剪，每床独立配置每扎件数 |
| 裁床条形码 | 每床一个条形码，裁床师傅扫码完成裁剪工序报工 |
| 裁床实际数录入 | 录入裁床实际产出，不限溢短，可修改 |
| 自动分扎 | 按规则拆分扎号，格式为床次-序号（如1-001） |
| 菲仔打印 | 每个菲仔含裁床条形码+扎号QR码，支持单扎/批量/重新打印 |
| 扎号管理 | 扎号列表+详情，状态为生产中/已完成，QR码自动失效与复活 |

## 裁剪工序说明

- 裁剪是第一道工序，包含在工序列表中
- 裁床师傅通过扫裁床条形码完成裁剪报工（无需逐扎扫码）
- 裁剪计件工资 = 该床实际件数 × 裁剪工价
- 扫裁床码后，该床所有扎号的裁剪工序自动完成
